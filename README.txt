
WEB MANAJEMEN PROYEK KONSTRUKSI
CV DUTA RIAU KONSULTAN

Cara menjalankan:
1. Install XAMPP
2. Copy folder ke C:/xampp/htdocs
3. Aktifkan Apache dan MySQL
4. Buka phpMyAdmin
5. Import database/db_manajemen_proyek.sql
6. Jalankan:
http://localhost/Duta_Riau_Web_Manajemen_Proyek_Lengkap/

Fitur:
- Dashboard monitoring
- Data proyek
- Status proyek
- Progress proyek
- Evaluasi proyek
